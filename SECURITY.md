# Security Policy

This repository is for public-safe Apple Silicon AI/ML experiments and synthetic benchmark scaffolds.

## Reporting

Open public issues only for public-safe bugs, documentation fixes, reproducibility problems, or security concerns that do not disclose sensitive information.

Do not report secrets publicly. Do not include credentials, tokens, private keys, private prompts, private data, private paths, or confidential records in issues, pull requests, discussions, screenshots, logs, or attachments.

## Data Boundary

This project does not accept private data. Use synthetic examples only.

No legal, confidential, personal, or proprietary materials should be submitted to this repository.
