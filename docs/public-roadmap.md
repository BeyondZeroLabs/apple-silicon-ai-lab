# Public Roadmap

This roadmap is intentionally lightweight and public-safe.

## Near Term

- Expand synthetic benchmark templates
- Add local-first setup notes for Apple Silicon tooling
- Document runtime approval gates without installing runtimes by default
- Add example result formats using invented data

## Later

- Add optional runtime-specific benchmark adapters after explicit approval
- Add reproducibility notes for approved local experiments
- Compare public-safe synthetic benchmark outputs across approved tools

## Not In Scope By Default

- Private data processing
- Secret-bearing examples
- Model downloads
- Runtime installs
- Deployment workflows
