# README Polish

Use this skill to improve public README clarity.

Guidelines:

- Keep tone direct, useful, and low-hype.
- Explain what the project is, what it includes, current status, roadmap, safety note, and license.
- Do not include private paths, secrets, sensitive personal references, real bridge receipts, or unsupported benchmark claims.
- Link to policy files instead of placing long internal safety blocks in the README.
