# Synthetic Benchmark Review

Use this skill when reviewing benchmark plans, prompts, matrices, or result templates.

Rules:

- Inputs must be synthetic or fictional.
- Do not use private records, private prompts, sensitive personal material, or cloud-synced private files.
- Do not invent measured results.
- Mark runtime installs, model downloads, and API calls as approval gates.
- Keep benchmark claims reproducible and modest.
