# License Recommendation

Status: Draft recommendation only. Do not treat this as a finalized license decision.

## Options

### MIT

MIT is short, familiar, permissive, and a good default for a simple public learning repository. It is easy for others to understand and reuse.

### Apache-2.0

Apache-2.0 is also permissive, but it includes explicit patent language and more formal terms. It is a better fit if Bryant wants patent clauses or expects broader commercial reuse concerns.

### No License Yet

No license preserves ambiguity and prevents clear reuse by others. This is acceptable while the repo remains local-only, but it is not ideal before public release.

## Recommendation

Recommend MIT for this public learning repo unless Bryant wants Apache-2.0 patent protections.
