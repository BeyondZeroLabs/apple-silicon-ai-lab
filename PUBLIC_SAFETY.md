# Public Safety Policy

This project is public-lane only.

Do not include:

- Secret values, API keys, tokens, passwords, or credentials
- `.env` files or local credential stores
- private legal case materials or evidence
- Google Drive private paths or hydrated placeholder content
- private runtime files
- private bridge receipts, handoffs, status logs, or traces
- Local user paths or home-directory paths
- Screenshots containing private data
- Model weights or downloaded AI runtime artifacts

Before any future push, run a public/private pre-push safety scan and manually review README, examples, notebooks, scripts, and benchmark files.
