# Contributing

Thanks for helping improve Apple Silicon AI Lab.

## Public-Safe Contributions Only

Contributions must use synthetic data and public-safe examples.

Do not include:

- Secrets, credentials, tokens, passwords, API keys, or private keys
- `.env` files or machine-specific credential files
- Local home-directory paths or private filesystem paths
- Legal, confidential, personal, or proprietary material
- Model weights or runtime artifacts unless explicitly approved later
- Generated files that include private prompts, private outputs, or sensitive logs
- Screenshots containing private content

## Development Notes

Keep examples small, reproducible, and local-first. If a change requires a runtime install, model download, API call, or paid service, document it as a future gate instead of assuming it is available.

## Pull Request Checklist

Before proposing changes, confirm:

- The content is public-safe
- Inputs are synthetic
- No secrets or private paths are present
- No binary artifacts are included unexpectedly
- Documentation explains any required future approval gates
